GDG ON CAMPUS - RIT HASSAN | CHALLENGE 01 WEBSITE

FILES
- index.html: website structure and content
- style.css: design and responsive layout
- script.js: navigation, theme switch, event filters, reveal animation and back-to-top
- images/: editable placeholder logo SVG files

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html with Live Server, or open it in a browser.
4. Keep the images folder beside index.html.

IMPORTANT BEFORE SUBMISSION

3. Replace sample event details with real/confirmed information.
